## 核心处理逻辑

### 1. 读取与剔除（账面毛利）
- 表头在第 2 行（第 1 行为分组标题），按表头名取列：`下单合同号/项目名称/客户名称/一级部门/二级部门/三级部门/实际销售员名称/行项目销售员/成本总价/税率/出具发票日/服务产品线/服务产品线类别`。
- 毛利表的`备注`列只用于"预提"剔除，不抓取到结果表；结果表`备注`列只按规则填充（不计费用 / 人工检查），其余行为空。
- 剔除：合同号为空、`外购`、`价外费用`、`暂未下单`；备注含"预提"。
- 多合同号按 `,` `，` 拆分（去空格）。

### 2. 基础字段映射
| 结果列 | 来源 |
|---|---|
| 索引1 | 合同号原文 + 税率（按 Excel 常规格式：0.06→`0.06`，0→`0`） |
| 下单合同号 | 账面毛利原值（多合同号保持原样） |
| 性质 | 固定"服务" |
| 平台 / 区域 / 事业部 | 三级 / 二级 / 一级部门 |
| 销售员 / 销售员编码 | 实际销售员名称 / 行项目销售员 |
| 开单成本（未税） | 成本总价 |
| 开单金额（含税） | 开单成本 × (1 + 税率) |
| 开单日期 | 出具发票日 |
| 服务产品线 / 类型 | 服务产品线 / 服务产品线类别 |
| 下单时间、运输方式、特殊备注、产品类别、产品线 | 留空 |

### 3. 付款匹配（付款表按"合同号"建索引）
- **HYX 开头**：候选项 = 各单条金额、同日合计、全部合计；|候选 − 开单金额| ≤ 1 → 付款金额取候选值、付款日期取其日期、激励取对应行合计；都不符 → 付款金额 = 开单金额，备注"人工检查"。
- **1Y0 / CY0 / 多合同号**：每个合同号按付款日期分组求和。
  - 全部合同号均无付款记录 → 付款相关列留空，日志计数。
  - 只有一个付款日期 → 付款日期取该日，付款金额 = 各合同号该日合计，激励求和。
  - 多个付款日期 → 拆行：
    - 原行：保留最早日期的合同号（及无付款记录的合同号），合同号用 `,` 重排；付款日期 = 最早日；付款金额 = 该日合计；开单金额 = 原金额 − 其余日期付款金额之和；成本 = 金额 / (1 + 税率)。剩余金额 < 0 时备注"人工检查"。
    - 新行：每个其余日期一行，紧跟原行；合同号 = 该日有付款的合同号；付款金额 = 该日合计；开单金额 = 付款金额；成本 = 金额 / (1 + 税率)；其余字段复制原行；索引1 按新合同号重算。

### 4. 派生字段（拆行后逐行计算）
- 付款金额（不含税）= 付款金额 / (1 + 税率)
- 发货款天数差 = 开单日期 − 付款日期（天）
- 贷款利率：天数差 ≤ 8 → 0；> 8 → 配置中"开单日期所在年份"的利率（配置缺失 → 留空并日志提示）
- 总财务费用 = (天数差 − 8) × 付款金额 × 贷款利率 / 365（天数差 ≤ 8 时为 0）
- 扣款时间 = `{年}Q{季度}`，扣款月份 = `{月}月`（按开单日期）
- 使用激励金额 = 华为激励 + 超聚变激励（空记 0）
- 核查 = 开单金额 − 付款金额；核查-使用激励 = 核查 − 使用激励金额

### 5. 是否已算过费用 与 备注
- 索引1 在累计表（按"索引1"列）中命中 → 是否已算过费用 = 该索引，备注"不计费用"。
- 不计费用其他条件（满足其一）：区域="培训" 且 项目名称含 考试券/囤券/半导体客户培训项目；开单成本 ≤ 0。
- 其余行 |核查-使用激励| > 5 → 备注"人工检查"。多个备注用"；"连接。

### 6. 界面与输出
- 三行文件选择（账面毛利 / 付款信息 / 累计下单费用，xlsx 过滤）；利率编辑框（每行 `年份=利率`，支持 `0.0828` 或 `8.28%`），核算前校验并回写配置。
- 点击"核算"：校验三个文件 → 另存为对话框（默认账面毛利同目录 `下单费用.xlsx`，禁止覆盖三个输入文件）→ 后台线程计算，进度条 + 日志（读入行数、剔除行数、拆行数、付款未匹配数、不计费用/人工检查数、缺利率年份；成功后输出结果文件保存路径；有报错才输出报错信息，无报错不输出）→ 完成后可"打开结果文件"。
- 错误处理：文件打不开、缺必需列、年份格式错误 → 弹窗提示具体文件与列名，不生成半成品。
