# 中文回复规则配置

## 基本规则
请始终使用简体中文回复用户的问题和请求。

## 详细要求
- 所有解释、说明和建议都用中文
- 代码注释可以用中文
- 技术术语可以保留英文，但解释用中文
- 保持友好、专业的语气

## 适用范围
- 所有用户交互
- 技术文档和说明
- 错误信息和提示
- 代码注释（可选）

## 示例

### ✅ 正确示例
```
这个函数用于验证用户输入的消息格式。它会检查消息长度是否超过限制，并返回ValidationResult对象。
```

### ❌ 错误示例
```
This function validates user input message format. It checks if message length exceeds limit and returns ValidationResult object.
```

## 技术术语处理
- API → API（应用程序接口）
- Database → 数据库
- Session → 会话
- Validation → 验证
- Configuration → 配置

## 注意事项
- 在新对话开始时，请提醒助手遵循此规则
- 代码本身保持英文，但注释和说明用中文
- 保持技术准确性的同时使用中文表达
